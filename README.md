# KubeJS Editor

**游戏内 KubeJS 可视化配方与内容编辑器。** 面向 Minecraft **1.21.1 / NeoForge**，当前版本 **0.23.0**。

从 JEI 拖入材料和产物，修改机器配方、编辑生物掉落、注册物品和方块。编辑器生成 KubeJS 脚本，并提供待办、检查、备份、批量撤销和回滚。强制兼容通过读取真实数据来源和修改原生字段，尽量复用模组已经公开的数据接口。

## 功能

- **配方编辑**：新增、替换、禁用已有配方；支持 JEI 拖放、数量、组件、概率及原生参数。“替换／新建”可直接切换并保留当前编辑内容，新建时自动分配未占用的 ID。
- **Create 集成**：常见加工设备画布、动力合成、序列组装和部分附属加工。
- **内容注册**：物品、食物、工具、防具、常用方块、单格耕地作物与可配置存储方块。
- **背包取样**：打开可移动子窗口，将背包中的实际物品拖入配方槽位，保留名称和组件数据。
- **生物掉落**：按生物或原生掉落表增删掉落项、修改数量、基础概率和组件。
- **数值参数与字段补丁**：修改同一份配方数据中的数值、原始字段、物品／流体 ID、组件和列表；未自动识别的字段可通过字段树选择，支持精确批量替换、预览、撤销和原生格式检查。
- **自动选择适配方式**：按实际来源、槽位覆盖、字段和规则问题比较候选，保留已确认的手动映射。
- **修改管理**：自动保存待办，集中查看原始 JSON、生成代码和差异；支持一次重载的批量撤销、文件冲突检查和失败回滚。
- **配置编辑**：读取模组公开的配置定义，区分全局机器设置与单条配方参数。
- **原生数据包导出**：支持配方、掉落表、谓词、物品修饰器及已支持的原生注册表覆盖；目标环境具备对应模组和依赖时，可通过游戏的数据包机制加载。

| 项目 | 声明范围 |
|---|---|
| Minecraft | **仅 1.21.1** |
| Java | **21** |
| NeoForge | **[21.1.199, 21.2)** |
| KubeJS | **2101.7.2-build.368 起**，同时满足其自身依赖 |

安装时需同时满足各依赖自身的版本要求，不能任意交叉组合；例如部分较新的 JEI 要求较新的 NeoForge。当前声明范围适用于 Minecraft 1.21.1 / NeoForge，不适用于 Forge、Fabric 或其他 Minecraft 版本。

## 强制兼容

强制兼容优先寻找普通配方、公开包装来源、完整编码匹配或原生数据包注册表，再选择覆盖较完整的编辑方式。实际可编辑范围取决于模组的数据来源和加载方式。

- 有真实可写来源时，可直接按原生格式修改尚未自动识别的槽位和字段，尽量保留未知字段、标签、组件与独立数量。
- 原生格式校验、实际注册项和加载结果决定修改是否有效。单独改动 JEI 展示对象无法改变机器实际加工。
- 来源有歧义时需要确认；手动选择数据源后仍需核对它与当前配方的关系，修改可能影响所有共享该来源的机器。
- 配置或硬编码计算、私有管理器、事件追加掉落等机制，可能无法通过配方或掉落表修改；当前不提供任意 Java 逻辑或私有字段写入。
- 普通配方、掉落表、谓词和物品修饰器通常通过重载生效；启动期注册表、内容注册及部分配置需要重启。编辑器管理的原生覆盖需要保留兼容版本的编辑器；单独导出的原生数据包通过游戏加载。
- 直接应用面向本机单人世界／集成服务端，当前不提供远程服务器写入。

## 开始使用

1. 关闭游戏，安装主 Jar 及匹配的 KubeJS、Rhino、JEI；同一实例只保留一个编辑器版本。发布包附有 PowerShell 7 安装器，可备份旧 Jar。
2. 进入世界按 **K**，或执行 `/kubejseditor`（别名 `/kjseditor`）。
3. 从 JEI 配方按钮进入，或在最后一栏 **强制兼容** 选择机器／配方；通过上方 **替换／新建** 按钮选择编辑模式。
4. 修改后检查待办和代码差异，再一键应用。批量撤销位于 **已有修改 → 批量删除**。

配方编辑页上方可直接打开 **背包取样、数值参数、字段补丁、代码 / JSON**。拖动背包取样窗口的标题栏可移动窗口，物品可直接拖入配方槽位；无法自动绑定的槽位可通过字段树选择对应字段。

生物掉落入口：**修改现有 → 生物掉落**。自动适配入口：配方编辑页 **更多 → 适配方式（自动优选）**。原生数据包导出入口：主界面 **更多 → 导出原生数据包**。
